# 家具展厅咨询视频脚本工作单

本工作单用于一个已经通过人工审核的选题。它让脚本、制作条件和后续测试使用同一份输入。它不代替选题审核，也不自动授权拍摄、发布或广告投放。

## 输入卡

开始写脚本前，尽量取得以下信息：

| 类别 | 必填内容 |
| --- | --- |
| 选题审核 | 选题编号、题目、审核结论、审核人、审核日期、审核意见 |
| 需求证据 | 平台或客户来源、取样日期、真实问题摘要、证据边界 |
| 目标客户 | 所处阶段、使用场景、一个核心问题、期待结果 |
| 内容命题 | 场景冲突、可感知代价、一个专业判断、一个主要证明 |
| 到店价值 | 到店后可实际比较、测量、体验或确认的事情 |
| 咨询动作 | 一个行动指令、承接入口、承接人和服务范围 |
| 产品与空间 | 产品编号、实测尺寸、材质、现有展区、可拍状态 |
| 制作资源 | 人员、设备、时间、营业影响、搬动限制和安全条件 |
| 素材权利 | 图片、视频、人物、音乐、字体及广告使用权状态 |
| 测试信息 | 时长版本、唯一主要测试变量、需要记录的结果 |

只有“选题审核已通过”是进入完整脚本的硬条件。其他缺失信息写成“待确认”，并从口播中删除依赖该信息的具体承诺。

## 输出模板

标题、标题层级、字段名和逐镜表头应保持不变，以便 `scripts/validate_script.py` 检查。

```markdown
# [选题编号]｜[视频标题]

## 状态

- 脚本状态：候选
- 选题审核：已通过
- 审核人：[姓名或明确身份]
- 审核日期：[YYYY-MM-DD]
- 主要目标事件：咨询
- 拍摄授权：[未确认／未授权／已授权]
- 发布授权：[未确认／未授权／已授权]
- 广告投放授权：[未确认／未授权／已授权]
- 素材权利状态：[待确认／部分确认／已确认]

## 已审核选题

- 具体问题：[一个问题]
- 目标客户：[阶段 + 场景 + 问题 + 期待结果]
- 需求信号：[来源、取样日期和忠实摘要]
- 证据边界：[该证据能说明什么，不能说明什么]

## 输入与缺失信息

- 已确认：[产品、空间、人物、尺寸、服务等]
- 待确认：[不编造；没有则写“无”]
- 所需素材：[逐项写清]
- 承接入口：[实际咨询入口]
- 承接人：[实际负责人]

## 核心命题

- 场景冲突：[用户能认出的具体处境]
- 可感知代价：[走路不便、返工、退换、整体不协调等]
- 专业判断：[只写一个]
- 主要证明：[动作、尺寸、材质、比例或其他可观察证据]
- 到店价值：[到店后能实际完成什么]
- 单一行动指令：[只保留一个咨询动作]

## 制作难度判断

- 建议拍摄等级：[L0／L1／L2／L3 中的一个]
- 最重动作：[本脚本最难实现的动作]
- 重家具处理：[不搬动／利用正常换场一次拍摄／其他真实安排]
- 所需人员与设备：[具体数量与工具；无则写“无特殊要求”]
- 营业与安全条件：[具体影响和保护条件]
- 选择理由：[为什么该证明既可信又可实现]

| 10–20 秒 | 专业判断 | [...] | [...] | [...] | [...] | [...] | L0 | [...] |

| 35–42 秒 | 到店价值 | [...] | [...] | [...] | [...] | [...] | L0 | [...] |

## 拍摄前检查

- [ ] 产品编号和实测尺寸已核对。
- [ ] 画面里的空间、产品和人物可拍。
- [ ] 服务内容、承接入口和承接人已确认。
- [ ] 所有第三方素材和人物已取得所需广告权利。
- [ ] L2/L3 动作已确认人员、工具、地面保护和恢复安排。
- [ ] 模拟、示意和不同展区画面已在屏幕文字中标明。
- [ ] 拍摄、发布和广告投放分别取得所需授权。

## 禁用表达

```

## 填写规则

1. 逐镜表通常保留 5–8 个有效镜头；信息更少时缩短视频，不增加空镜。
2. “说服任务”说明镜头为什么存在，不写“氛围”“高级感”等无法检查的空泛目的。
3. “证明点”写观众从画面能观察到的事实，不重复口播。
4. “实现方式”必须具体到人物动作、测量方法、机位或已有素材。
5. 每一行都填 `L0`、`L1`、`L2` 或 `L3`。
6. `L2/L3` 行的“替代方案”必须给出可以实际拍摄的 `L0/L1` 方法。
7. 单一行动指令可以在最后镜头重复一次，但不得同时要求另一种行动。
8. “当前结果”在没有真实投放数据时只能写“尚未投放验证”或对应的真实状态。
